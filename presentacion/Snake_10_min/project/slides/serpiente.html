static Posicion cuerpo[CAPACIDAD_CUERPO];      // 32 × 16 = 512
cabeza = (cabeza + 1U) % CAPACIDAD_CUERPO;     // la cabeza avanza
cola   = (cola   + 1U) % CAPACIDAD_CUERPO;     // la cola avanza

No hay límite de longitud: el arreglo tiene una posición por píxel (512, o 1024 con dos paneles).

El cuerpo es un buffer circular: no se mueven los datos, solo los índices de cabeza y cola. Al avanzar se escribe la posición nueva en cabeza+1 y, si no se comió manzana, se apaga el píxel de la cola y la cola avanza. Si se come manzana, la cola no avanza y la serpiente crece. El módulo da la vuelta al principio.
