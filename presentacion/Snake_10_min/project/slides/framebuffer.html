Framebuffer y color de 3 bits

static volatile uint8_t framebuffer[PANEL_ALTO][PANEL_ANCHO];

// encender_pixel ignora lo que cae fuera del tablero
if (x < PANEL_ANCHO && y < PANEL_ALTO) {
    framebuffer[y][x] = (uint8_t)color;
}

1 rojo

6 cian

Bit 0 = R, bit 1 = G, bit 2 = B. volatile: main escribe y la interrupción de TIM3 lee.

El framebuffer guarda un byte por píxel con tres bits de color (R=1, G=2, B=4), lo que da siete colores más negro. Es volatile porque la interrupción lo lee mientras main lo escribe. encender_pixel comprueba los límites para no escribir fuera del arreglo. Pregunta típica: la condición de carrera entre ISR y main; el doble buffer (paso 12) la evitaría.
